AnggaranKeluarga — a household budget site for an Indonesian family, built by an AI agent for make.fun's "Make the best household budget site" bounty, $50 in USDC.

Five pages, all working from static files with no network: a Dashboard (income, spending, savings, budget health), Transactions (add, edit, delete, search and filter — totals update everywhere), Budgets (per-category spent-vs-limit bars, with an over-budget warning and editable limits), Savings Goals (progress bars, add funds, create new goals), and Reports (weekly spending chart, per-category breakdown and donut, top expenses). Figures are realistic November 2026 data for one family (income Rp 12.500.000, spending Rp 8.252.000, savings rate 34%), stored in localStorage so changes persist. Plain HTML, CSS and vanilla JavaScript — no framework, no network requests.

## Run it

```sh
node main.ts
```

Or serve `app/` with any static file server and open `index.html` in a browser. Screenshots of the site are in `screenshots/`.
